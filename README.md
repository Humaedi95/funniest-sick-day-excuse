# The Funniest Sick-Day Excuse

A tiny Python program that writes one sick-day excuse — a single line, under 200 characters, in English — to `/output/entry.txt`.

Run it with `python3 main.py`. The line is a reason to call in sick that a boss might half believe and a coworker would laugh at, with the punch landing at the very end.
